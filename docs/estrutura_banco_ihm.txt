CONVENÇÕES
──────────────────────────────────────────────────────────────────────────────
  PK  = Primary Key (chave primária, auto-incremento SERIAL)
  FK  = Foreign Key (referência a outra tabela)
  NN  = NOT NULL (obrigatório)
  UQ  = UNIQUE (valor único na tabela)
  DEF = DEFAULT (valor padrão)
  idx = índice recomendado para performance

================================================================================
  COMPONENTES QUE ESCREVEM NO BANCO IHM
================================================================================

  detector_amv.py   → ihm.alarmes (tipo: 'Falha Operacional')
                    → ihm.equipamentos (status_id)
                    → ihm.historico_status

  watchdog.py       → ihm.alarmes (tipo: 'Falha de Comunicacao')
                    → ihm.equipamentos (status_id)
                    → ihm.historico_status
                    Lê: ihm.equipamentos JOIN ihm.fontes_dados
                    Lê: public.dados_monitoramento (ou fonte configurada)

  API FastAPI       → ihm.alarmes (reconhecido_em, resolvido_em)
                    → ihm.usuarios (ultimo_acesso)

  IHM-CMA frontend → apenas leitura (polling a cada 10s)
